# Governança de dados — gate para dados reais

Este documento começa como checklist. Nenhum dado real de grupos deve entrar no projeto antes de as decisões abaixo serem aprovadas.

- [ ] Definir finalidade e base de tratamento.
- [ ] Definir responsáveis e perfis de acesso.
- [ ] Definir retenção de texto bruto, fatos, sinais e logs.
- [ ] Definir anonimização ou pseudonimização de `sender_ref`.
- [ ] Definir tratamento de nomes de grupo e territórios.
- [ ] Definir provider e minimização para processamento com LLM.
- [ ] Definir procedimento de exclusão e resposta a incidente.
- [ ] Confirmar que o produto não realiza perfilamento individual.
